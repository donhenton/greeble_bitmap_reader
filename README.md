# Usage.md — Greeble Reader (v12)

## What This Tool Does (Quick Reminder)

This project takes:
- A **JSON map** (generated by ChatGPT or another LLM)
- A matching **PNG overlay image**

…and uses them inside **Blender** to:
- Create a panel
- Overlay the map visually
- Populate it with **greeble objects** from 3 categories:
  - `large`
  - `medium`
  - `small`

It then generates multiple examples arranged in a grid for comparison.
The github project source is main.py and the files in the greeble_reader folder.

---

## Mental Model (Important)

Think of the system as:

JSON map → regions → object placement → Blender scene

Each region:
- Defines **where**
- Defines **what size category**
- The reader randomly picks objects from your collections

## Blender Setup (You WILL Forget This)

### 1. Open Blender
- Open your `.blend` file with your greeble collections

### 2. Required Collections

You must have collections matching:

large
medium
small

(Exact names come from `config.py` → `COLLECTION_BY_TYPE`)

Each should contain objects to scatter.

## Running the Tool

### Step-by-step:

1. Open `main.py` in Blender’s Text Editor
2. Press **Run Script**

That’s it.

---

## What Happens When You Run It

- Finds maps in `generated_maps/`
- Picks maps starting at `START_MAP_INDEX`
- Generates `EXAMPLE_COUNT` variations
- Builds a scene collection:

Generated_Example_Grid

Inside it:
- Each example gets its own collection
- Each example includes:
  - Panel
  - Overlay image
  - Placed objects

---

## Key Controls (Edit in `main.py`)

```python
START_MAP_INDEX = 0
EXAMPLE_COUNT = 10
```

### Use Cases

| Goal | Setting |
|------|--------|
| Test one map repeatedly | `START_MAP_INDEX = X`, `EXAMPLE_COUNT = 1` |
| Browse multiple maps | increase `EXAMPLE_COUNT` |
| Skip earlier maps | increase `START_MAP_INDEX` |

---

## JSON Format (What the Generator Must Produce)

Each JSON must include:

```json
{
  "canvas": {
    "width": ...,
    "height": ...
  },
  "regions": [
    {
      "type": "large | medium | small",
      ...
    }
  ]
}
```

### Key Idea

- `type` determines which collection is used
- The reader does NOT validate heavily — bad input = weird results

---

## How Placement Works (Important Behavior)

- Each region:
  - Selects a random object from its collection
  - Scatters it inside the region
- Placement logic lives in:
  placement.py → scatter_region()

---

## Overlay System

Each example also includes:
- A visual PNG overlay
- Helps you **debug region placement**

If things look wrong:
→ Compare objects vs overlay

---

## Grid Layout

Examples are arranged using:

grid.py → grid_position()

So you get a **visual comparison board** automatically.

---

## Common Mistakes (You Will Make These Again)

### 1. Nothing appears
- Collections are empty or misnamed

### 2. Objects not matching regions
- JSON `type` doesn’t match collection names

### 3. Maps not loading
- JSON/PNG naming mismatch

### 4. Script import errors
- You didn’t run from Blender Text Editor
- Path wasn’t added correctly (handled in `main.py`)

---

## Fast Debug Checklist

If something’s broken:

1. Does Blender have `large / medium / small` collections?
2. Are there objects inside them?
3. Do JSON + PNG names match?
4. Does JSON have `"regions"`?
5. Try `EXAMPLE_COUNT = 1` to simplify

## Advanced Notes (You’ll Care Later)

- Multiple examples = same map, different random selections
- System is designed for **batch exploration**
- JSON controls structure, not exact objects
- Object identity is intentionally **randomized**
