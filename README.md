# README

## 

#### Usage:

The greeble\_bitmap\_reader will run main and the code will read the data from the generated\_maps folder. Each data
instruction consists of a png and json file. The json file contains the layout data and the png file is a diagnostic
image that describes the layout. Moving files in and out of the generated\_maps folder will make them visible.

#### Blender File Setup: 

The file contains three collections for the large, medium, and small greeble. The contents of these files can be modified
at will, but should not be committed for arbritary changes. A copy should be made and the version under source control
should be maintained with vanilla objects









#### Folders:

* generated\_maps: required folder read by blender python contains the designated maps
* greeble\_reader: python packages
* storage: other possible maps stored by type
* meshy\_images: bitmaps used to create meshy models
